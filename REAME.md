# Telecom Customer Churn Prediction

## Project Overview
This project uses machine learning to predict customer churn in the telecommunications industry. The goal is to identify customers who are likely to leave the service.

## Objectives
- Analyze customer data and identify churn patterns.
- Perform data cleaning and exploratory data analysis (EDA).
- Build and evaluate machine learning classification models.
- Identify factors that influence customer churn.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Google Colab

## Project Workflow
1. Data loading and preprocessing
2. Exploratory data analysis and visualization
3. Feature engineering and encoding
4. Model training and evaluation
5. Model comparison and churn prediction

## How to Run
1. Open the notebook in Google Colab.
2. Upload the dataset or configure the dataset path.
3. Run the notebook cells in order.

## Results
The notebook contains the model evaluation results and performance comparisons.
